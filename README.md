# Backend Practice

This repo is a collection of small backend practice projects.

I use it to learn Express, Node.js, APIs, MongoDB, and basic backend project structure by building small apps instead of one big app.

## What Is In This Repo

- `express-learn` for basic Express practice
- `npm-learn` for simple Node and npm setup practice
- `boilerplate-mongomongoose` for MongoDB and Mongoose basics
- `project-timestamp` for a timestamp API project
- `project-headerparser` for a request header parser project
- `project-urlshortener` for a URL shortener project
- `project-filemetadata` for file upload and file metadata practice
- `project-exercisetracker` for exercise tracking practice

## How To Use This Repo

Each folder is its own small project.

Go into the folder you want, install packages there, and run that project from that folder.

Example:

```bash
cd project-timestamp
npm install
npm start
```

## Why This Repo Exists

This repo is mainly for practice.
Some folders are simple on purpose because the goal is to understand backend concepts step by step.

## Notes

- Each project has its own files and setup
- Some projects may need environment variables
- Some projects are experiments or learning exercises, not polished apps
